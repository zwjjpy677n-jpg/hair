# ヘアスタイル試着アプリ 設計

## 目的・背景
自分の顔写真と、SNSで見つけた髪型の写真をアップロードすると、自分の顔にその髪型を重ねた画像を見られる。
美容院に行く前に「この髪型が自分に似合うか」を自分で確かめるためのもの。使うのは本人だけ。

## ゴール
- スマホのブラウザでURLを開くだけで使える（インストール不要）
- 費用ゼロ（サーバー・有料APIなし）
- 写真は端末の外に送らない（すべてブラウザ内で処理）
- 写真2枚を選べば、髪が自動で切り抜かれ、自動で顔に位置合わせされる
- ずれは指で直せる（ドラッグで移動、ピンチで拡大縮小・回転）、はみ出しは消しゴムで消せる
- 結果画像を端末に保存できる
- 自分の元の髪を消してから新しい髪を重ねる（ユーザーの要望。「自分の顔と髪型を合成する感じ」にしたい）
- 髪レイヤーを左右反転できる（自撮りの鏡写し対策。設計者の判断で追加）

## ゴールにしないこと
- AI生成によるリアルな仕上がり
- 髪色の変更、髪型のお気に入り保存、アカウント、他人との共有機能
- ネイティブアプリ化、PC向けの最適化（PCでも動けばよいが、作り込まない）

## 失敗とみなすこと（動いていてもダメなもの）
- 写真がどこかに送信される
- スマホで操作しづらい（ボタンが小さい、指で位置合わせできない、横スクロールが出る）
- 毎回ほぼ手で合わせ直さないと使えないほど自動の位置合わせがずれる

## 制約
- 対象端末: ユーザーの iPhone（Safari）を最優先。Android Chrome でも動けばよい
  - iOS の不具合を避けるため、MediaPipe は GPU で失敗したら CPU で動かす。画像は長辺1024px程度に縮めてメモリを抑える
- 髪型写真は、正面から顔が写っているものが多い（ユーザー回答）。両目を基準にした位置合わせで足りる前提
- 静的ファイルのみ。GitHub Pages で公開
- ビルド工程なし（素の HTML/CSS/JS）。依存は CDN から読み込む
- 画像認識は MediaPipe Tasks Vision（`@mediapipe/tasks-vision`、jsDelivr、バージョン固定）
  - 髪の切り抜き: Image Segmenter + hair_segmenter モデル
  - 顔の位置: Face Landmarker
  - モデルファイルは Google の公開ストレージから読む（初回数MB）。ここで送るのはモデルを取りに行くリクエストだけで、写真は送らない

## 検討した作り方
- **A. 自動切り抜き＋自動位置合わせ＋手で微調整**（採用）。手間が少なく、仕上がりがいちばん良い。初回にモデルを読み込む時間がかかる
- B. 指でなぞって手動で切り抜く。軽くて単純だが、毎回手間で仕上がりも雑。不採用
- 無料のAI生成サービス。写真を外部に送るうえ不安定。不採用

ユーザーが A を選んだ。

## 仕組み
1. 顔写真と髪型写真を選ぶ（`<input type="file" accept="image/*">`。カメラ撮影も可）。EXIF の向きを正しく扱い、長辺は1024px程度に縮める
2. 髪型写真から髪のマスクを作り、透明背景の「髪レイヤー」を作る。マスクの境界は少しぼかす
3. 両方の写真で顔のランドマークを取る。左右の目の中心を2点の基準にして相似変換（移動・拡大・回転）を求め、髪レイヤーを顔写真の座標系に変換する
4. 元の髪を消す（初期状態でオン、切り替え可）: 顔写真からも髪のマスクを取り、新しい髪レイヤーで隠れない部分（マスクを少し広げたもの）を周りの色で埋める。埋め方は周囲の画素から内側へ色を広げる簡易的な穴埋め（拡散や Telea 系）で、iPhone でも数秒以内に終わる軽さにする。重いライブラリ（OpenCV.js など）は避ける。新しい髪を動かしたら埋める範囲も更新する（重ければ指を離したときに更新）
   - 限界（ユーザーに説明済み）: 背景が無地なら目立たないが、背景が複雑な場合や、髪が肩・服にかかる場合は跡が不自然になる。画面に「髪をまとめて撮るときれいに仕上がる」というコツを表示する
5. 顔写真の上に髪レイヤーを重ねて表示する
6. 手で調整する: 1本指ドラッグで移動、2本指ピンチで拡大縮小と回転、消しゴムモード（ブラシの太さを選べる）、元に戻す、自動位置にリセット
7. 保存する: 合成結果を JPEG にして、`navigator.share({files})` で iOS の共有メニューを開き、「画像を保存」で写真アプリに入れられるようにする。使えない場合は画像を全画面で表示して、長押しで保存してもらう

### エラー時の動き
- 顔が見つからない場合: どちらの写真で見つからなかったかを表示し、その写真の両目を2回タップして指定してもらう（設計者の判断）。指定したら通常どおり自動で合わせる。スキップした場合は髪レイヤーを中央に置き、手で合わせる
- 髪が見つからない場合: その旨を表示する

## 画面（スマホ縦向き、1画面）
```
[ 顔写真を選ぶ ] [ 髪型写真を選ぶ ]
┌────────────────────┐
│  合成プレビュー（指で操作）  │
└────────────────────┘
[移動] [消しゴム ●太さ] [左右反転] [元に戻す] [リセット]
[ 元の髪を消す: ON/OFF ]
[ 保存 ]
```
- 読み込み中・処理中は進み具合を表示する
- 文言は日本語

## 作る人に任せること
- 見た目のデザイン、ファイルの分け方
- ぼかしの強さ、ブラシの太さの段階、縮小サイズの細かい値
- テストの方法（位置合わせの計算など、純粋な関数は単体テストを書く）
