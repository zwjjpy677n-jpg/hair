# ヘアスタイル試着

自分の顔写真と、SNS などで見つけた髪型の写真を選ぶと、自分の顔にその髪型を重ねて見られる Web アプリです。iPhone の Safari 向けに作っています。

- 写真はスマホの中だけで処理され、どこにも送信されません（初回だけ画像認識のデータ 約10MB をダウンロードします）
- 費用はかかりません

## 使い方

1. 「顔写真を選ぶ」で自分の写真を選ぶ（髪をまとめて、無地の壁の前で撮るときれいに仕上がります）
2. 「髪型写真を選ぶ」で試したい髪型の写真を選ぶ（正面を向いた写真がおすすめ）
3. 自動で位置が合います。ずれていたら指で直します
   - 1本指: 移動
   - 2本指: 拡大・縮小・回転
   - 消しゴム: 髪型写真の余計な部分を消す
   - 左右反転: 自撮りで鏡写しになった髪型を直す
4. 「元の髪を消す」で、はみ出した自分の髪を周りの色で塗りつぶします（背景が複雑だと跡が目立ちます）
5. 「保存」→ 共有メニューの「画像を保存」で写真アプリに保存

顔が見つからなかったときは、写真の両目をタップすると位置合わせができます。

## 公開のしかた（GitHub Pages）

1. このブランチを `main` にマージする
2. GitHub のリポジトリで Settings → Pages → Build and deployment の Source を「GitHub Actions」にする
3. `main` に push されるたびに自動で公開されます。URL は `https://<ユーザー名>.github.io/hair/` です

## 開発

```bash
npm test                      # 単体テスト
python3 -m http.server 8000   # http://localhost:8000 で確認
node tests/e2e/smoke.mjs face.jpg style.jpg [mediapipe-package-dir] [screenshot.png]
```

`smoke.mjs` は Playwright（iPhone 13 エミュレーション）で通しの動作を確認します。テスト用の写真はリポジトリに含めていないので、手元の写真を指定してください。
